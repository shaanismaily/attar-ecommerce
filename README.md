# 🌿 Attar E-commerce

A modern full-stack e-commerce platform for discovering and purchasing premium attars (alcohol-free perfumes).

This project is being built to simulate a real-world production application while exploring modern web development practices using React, TypeScript, Node.js, Express, and MongoDB.

> **Status:** 🚧 Under Development

---

## ✨ Features

### Customer

* Browse premium attars
* Search and filter products
* Product details page
* User authentication
* Shopping cart
* Wishlist
* Secure checkout
* Order history
* User profile management

### Admin

* Dashboard
* Product management
* Category management
* Order management
* User management
* Inventory management
* Sales analytics

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/shaanismaily/attar-ecommerce
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the backend directory.

Example:

```env
PORT=
MONGODB_URI=

ACCESS_TOKEN_SECRET=
ACCESS_TOKEN_EXPIRY=

REFRESH_TOKEN_SECRET=
REFRESH_TOKEN_EXPIRY=

CORS_ORIGIN=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```
